📸 Web Games - Captura de Pantallas

Guía para capturar las pantallas de demostración del proyecto

ℹ️ El servidor de desarrollo debe estar corriendo: npm run dev

✅ Pasos para capturar:

  1. Asegúrate de que el dev server está corriendo en http://localhost:3001
  2. Haz clic en "Abrir en navegador" para cada pantalla
  3. Espera a que cargue la página completamente
  4. En macOS: Presiona Cmd + Shift + 4 y selecciona el área a capturar
  5. En Windows: Presiona Win + Shift + S y selecciona el área
  6. Guarda la captura en public/screenshots/ con el nombre sugerido
npm run screenshots
